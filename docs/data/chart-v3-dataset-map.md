# Chart v3 dataset map

This map records the curated version-3 default dashboard against the retained simulation-exercise sources. It preserves the analytical coverage learned from the previous exercise dashboard while deliberately replacing its panel structure and version-2 chart configuration.

## Coverage decisions

- **Home:** 2 concise operational views.
- **Outbreak dynamics:** 10 views spanning national trends, mortality composition, provincial comparisons and deltas, synchronized municipal geography, aggregate municipal burden, a population relationship view, and a current KPI.
- **Health system:** 8 views. ICU and hospital bullets remain separate because capacity targets live in separate retained sources; the two-entity occupancy gauge exercises shared Collection Display.
- **Environmental surveillance:** 2 wastewater views.
- **Vaccination:** 2 status and trend views.
- **Public response:** 5 risk, adherence, and policy-value views.
- **Trust and wellbeing:** 6 trust, loneliness, mental-wellbeing, lifestyle, and resilience views.
- **Economy and staffing:** 4 economic and workforce views.

The chart builder still offers **timeline** and **swimlane** charts. They are not seeded here because none of the retained exercise sources contains an honest event plus start/end interval structure. Inventing intervals would misrepresent the evidence.

The provincial map-scatter views join the retained numeric `province_id` to the GeoJSON `id` property. This canonical identifier avoids the source-label difference between **Friesland** and the GeoJSON label **Fryslân** without dropping a province or mutating source evidence.

### Task 3 rendering integration requirement

The chronological choropleth deliberately prepares the complete 146,080-row harmonized history so clocks, joins, and synchronized analysis retain every measurement point. Static/live rendering must select one bounded initial time frame before geography option construction, and playback must project one active frame before building the map option. The full all-time mark set must not be spread into a single ECharts option or discarded from the analytical pipeline.

## Synchronization groups

- `municipal_outbreak` uses the chronological harmonized 2021 municipality source and `Datum` as its primary clock. The choropleth and municipality aggregate line use exact matching because they share the same observations.
- `national_outbreak` uses `bio_cases.date` as its primary clock. Its seeded line, mixed, grouped-bar, KPI, and bullet views use exact matching because their retained biomedical series share daily calendar observations. The occupancy gauge is intentionally excluded because its retained two-row snapshot has no time field.

All chart-local temporal matching keys are absent. Matching policy belongs only to synchronization groups and their members.
