# Cross-style journey matrix

This executable catalogue preserves the 71-entry dense-desktop journey inventory: 64 executable journeys, six coverage aliases, and one intentional exclusion. The retired Page Orbit inventory slot is represented by the live `build-page-command-form` journey.

The three columns below are 213 journey/style cells. They prove state reachability and do not constitute complete visual-region coverage. `PENDING_RENDER` is deliberately not a visual pass: browser capture and rendered disposition remain deferred. `COVERAGE_ALIAS` records a bounded existing-journey mapping; `OUT_OF_SCOPE` records the approved mobile exclusion.

The separate [Owned Visual-Region Inventory](OWNED-REGION-INVENTORY.md) currently contains 45 distinct region variants and therefore 135 generated region/style cells. That denominator changes with the live registry instead of being frozen to the historical journey count.

## Deterministic amendment status

Implementation and focused Node contracts cover ten shared style roles (`shell`, `command-bar`, `panel`, `editor`, `dialog`, `drawer`, `menu`, `status`, `table`, and `chart-cell`), their projection across theme roots, semantic-token style shadows, and geometry-invariant style declarations. Ledger role paint is flat; repeating horizontal ruling is a separate `ledger-register` material limited to chart-table and Source Viewer table regions. The Build command header, page navigation, global crown, View playback controls, and Present action dock share command-bar paint. The standalone chart-state recovery harness projects all three style IDs and consumes the shared status role. Audience option and DOM contracts retain the count-derived `28 / 18 / 40px` title/text/value tier for one or two displayed items and `24 / 16 / 34px` for three or four displayed items without changing saved chart configuration.

This is deterministic evidence only. The real cascade, computed geometry, mounted candidate closure, canvas repaint, and three-style contact sheets still require the intentionally deferred browser review, so all executable journey and region cells remain `PENDING_RENDER`.
