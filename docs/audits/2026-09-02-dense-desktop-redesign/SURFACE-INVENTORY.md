## Bounded alias rationale

| Alias | Executed authority | Equivalence boundary |
|---|---|---|
| `chart-editor-modal-contract` | `full-chart-editor-configure` | Same live full-edit journey and shared full-editor dialog chrome; the alternate modal host is not separately reachable. |
| `build-move-dialog-contract` | `build-create-page-dialog` | Same compact move/create utility shell, field stack, and footer geometry. |
| `build-move-confirmation-contract` | `delete-dashboard-content-dialog` | Same compact confirmation/danger shell and action-footer geometry. |
| `build-workspace-dialog-contract` | `build-standard` | Registry name resolves to the already-executed live Build workspace. |
| `source-viewer-dialog-contract` | `source-viewer-standard` | Registry name resolves to the same standalone source-viewer window and root. |
| `right-side-drawer-contract` | `dashboard-look-standard` | Dashboard Look is the stable concrete production instance of the registered right-side drawer. |

## Intentional exclusion

`mobile-view-custom-design` is reserved for a future purpose-built View-only mobile design. It is not graded by this desktop redesign. This exclusion does not apply to the below-1024 Build and Present gates, which were executed and passed.
