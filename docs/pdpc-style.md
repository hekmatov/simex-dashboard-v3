# PDPC style

PDPC is a selectable visual style (`pdpc`) and colour profile (`pdpc/brand`). It inherits Ledger geometry and surface treatment. Existing dashboard content and default selections are unchanged.

The only font-family style tokens are `--simex-style-body-font` and `--simex-style-heading-font`. CSS, text boxes, controls, tables and icon text reference these tokens. The chart renderer resolves them from computed styles before drawing, including rich labels, tooltips, legend pagination and custom graphics. Numeric labels use the heading token; code and other supporting copy use the body token. The internal chart adapter's `dataFont` property reads the heading token and does not introduce another style token.

PDPC assigns the same family stack to both tokens: the bundled PDPC Avenir face, then the bundled SimEx Inter. The supplied `Avenir Book.ttf` contains OpenType CFF data and is stored unchanged as `src/assets/fonts/AvenirBook.otf`. Its SHA-256 is `0a7f7fddb0844cf1ac94d602fc9ac13f34945ca7ee0773670e428428f3a1527c`. Headings use weight 700, synthesised from Book because no separate bold face was supplied. Font usage names belong in the JavaScript style definition; the CSS `@font-face` declaration only registers the asset. Charts wait for the resolved font faces before applying their typography so canvas measurements use the loaded font. Text embedded in raster images cannot respond to CSS tokens. Mathematical notation retains the existing specialised KaTeX glyph renderer.

Ledger retains its Inter/Georgia pairing. Humanist retains its text/display pairing. Instrument now uses its heading family for numeric text instead of a third monospace family. The former data and monospace CSS tokens have been removed rather than retained as aliases.

The palette centres on the guide's three primary colours: navy `#253162`, green `#258161` and cyan `#139cd8`. Green identifies active controls, navy anchors text and selection, and cyan identifies secondary and time-related elements. The first three chart series use green, cyan and navy. A pale green outer surface, neutral canvas, white panels and pale cyan chart surfaces give the profile variation without saturating every surface. Dark appearance uses related tints for readable text and marks. Small cyan text uses a darker variant for contrast. The guide's secondary red `#d72628` and lavender `#8d88ad` extend the chart palette, with supplementary ochre as the sixth colour. The guide's lavender RGB and hex specifications disagree; this profile follows the printed hex and swatch.
