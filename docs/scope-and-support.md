# Scope, limitations and support

Draft for the HeV-A26 engineering RC. Exact candidate/package identities and acceptance results remain to record. Production publication needs separate authorization.

SimEx is a static browser application for exercise preparation, exploration, presentation and debrief. The full workspace includes authoring/moderator tools. Paired PDPC participant outputs are read-only, each containing shared Scenario instructions and one discipline page. Data is fictional or repurposed for training; this is not a validated public-health decision system.

The human approved the PDPC logo, **Pandemic and Disaster Preparedness Center** name, brand colors and **“Fictional scenario · Exercise use only”** notice on 9 November 2026.

Browser edits, assets and caches belong to one browser profile/origin. Export a complete package before upgrading, clearing storage or changing device. Keep the original V6 package and compatible previous app: an older app cannot be assumed to read V7. Native charts remain Version 3; the RC dashboard/package format is Version 7.

Time controls and hidden charts do not restrict access to package bytes. Distribute reviewed derivatives that physically exclude unreleased information; keep the full original with the operator. Two static boundary layers are approved from 31 March 2027. Four unresolved data sources remain omitted; separate dated observations still follow each cutoff.

Phone support covers **View**. Build/Present retain their desktop-width advisory, recommending at least 1024 CSS pixels. Performance acceptance applies only to recorded devices/conditions in the [rehearsal packet](rehearsal.md). A first hosted visit needs connectivity; warmed offline reopening and standalone HTML have separate checks.

Audience runs on the same computer/origin. It is passive apart from its supported date-position interaction. A local fallback does not prove projector agreement. Accepted time/matching updates propagate; after package imports or binding/source edits, reload Audience and verify its charts.

There is no new backend, account system or server-side access control. Optional Quorum integration requires catalogue contract 3; the inspected local validator accepts contract 2 only. Real contract-3 integration is unverified. Standalone use remains independent.

Scenario-authoring is paused. Additional mobile options, chart-V2 compatibility and deferred issue #22 are excluded; see the [issue record](superpowers/plans/2026-10-30-v3-open-issues.md).
