What changed

View: attention strip

A Section can now carry role: "attention". In View it renders above the page body as a band of KPI cards, ignoring authored chart footprints. Each card can carry a drill link to a body Section or chart; activating it scrolls there, moves focus, and highlights the target for 1.6 seconds. Only kpi and deltaCard charts may live in the strip; the config validator, the layout move guards, and the role switch all refuse anything else by name.

  • Contract: optional role on sections and drill on panel wrappers, version 6 unchanged.
  • Files: sectionRoles.js, DashboardAttentionStrip.jsx, drillNavigation.js, canvas wiring, structure commands set-section-role and set-panel-drill.

View: page time context

Pages with temporal charts show a Page time readout in the crown's context strip. Set page time opens playback with a new explicit Whole page source, scope All page charts, so every chart on the page reads as of one time. The Chrono source selectors gain a Whole page option. No categorical filters were added.

Build: persistent rails and one command row

The Dashboard map drawer and its crown toggle are gone. Build is now a three-column frame: a Structure rail on the left, the canvas, and a Properties pane on the right. The properties pane replaces the old inspector and adds the Section Role choice and per-card Drill links. Below 1024px the rails fold into disclosures above and below the canvas.

The command row is three labelled groups, Insert, Libraries, Session. Scene Studio moved out of the retired More drawer into Libraries.

Build: section and panel menus

The five buttons on every section header are now one Actions menu (Rename, Move earlier, Move later, Move to Page, Merge, Remove). The four icon controls on every panel are one trigger that opens a menu (Edit chart, Move, Start section here, Remove chart) and still works as the drag handle. A shared ActionMenu component provides arrow-key, Home, End, and Escape handling with focus return.

Mobile View

At widths of 767px or less in View, the crown collapses to one row: the SimEx mark, the mode switcher, and a disclosure named after the active page. The disclosure holds the dashboard title and scenario, the page list, the pinned actions (Theme, Chrono view, Compare charts), and the metadata pairs. The header keeps only the page title and description. Every chart footprint is capped at clamp(240px, 52vh, 420px), panels stack in one column, and the attention strip becomes a horizontal snap-scrolling row.
