# Dashboard visual-language palette catalogue

This catalogue records the exact prototype paint tokens for the 15 approved, saveable Sketch 003 palettes. **Original baseline** is review-only and excluded. The rejected **Sunrise — Contrast tuned** and **Lakeside — Contrast tuned** variants remain preserved in the interactive sketch but are excluded from the portfolio tables.

The values below are the palette-owned CSS tokens. Style grammar remains an independent setting, and **Standard chart colors** may independently override only D1–D6 in the running dashboard.

Legend:

- Base: **OUT** outer application, **CAN** dashboard canvas, **PAN** chart/panel, **ALT** alternate panel.
- Text/rules: **INK**, **INK-S** soft ink, **INK-F** faint ink, **RULE**, **RULE+** strong rule.
- Controls: **ACC** accent, **ACC-S** soft accent, **ON-ACC** content on accent, **FOCUS** focus indicator.
- States: **SEL/SEL-S** selected, **CHR/CHR-S** Chrono, **INFO/INFO-S**, **OK/OK-S** success, **WARN/WARN-S**, **ERR/ERR-S**.
- Chart frame and series: **GRID** gridline, **MARK** neutral chart-mark boundary, **D1–D6** ordered chart-series slots.
